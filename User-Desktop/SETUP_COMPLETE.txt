🎯 HOW TO USE:

For new screens:
```python
from configs.screen_utils import ArabicScreenMixin

class YourScreen(ArabicScreenMixin, Screen):
    pass  # Arabic support automatically added!
```

For existing screens:
```python
from configs.arabic_fonts import apply_arabic_font

# In your __init__ or setup method:
self.bind(on_enter=lambda *args:
    [apply_arabic_font(w, w.text) for w in self.walk(restrict=True)
     if hasattr(w, 'text') and w.text])
```

In KV files, just use Arabic text:
```kv
Label:
    text: 'Save - حفظ البيانات'
```
