2. Language switcher popup opens with English/Arabic options
3. User selects desired language
4. Language manager notifies all observers (including Insert screen)
5. Insert screen's on_language_changed() method is called
6. setup_localization() → update_texts() → apply_fonts() sequence runs
7. All text elements instantly update to selected language
8. Arabic fonts applied automatically when Arabic is selected
